# water-change

[get the cleaner shrimp out](https://en.wikipedia.org/wiki/Lysmata). get a list of files either larger than specified size or not accessed in the last specified days. used to help clean up messes created by game developers.

Run: `python waterchange.py <directory> <days old> <size in MB>`

What to do with results is up to you.
